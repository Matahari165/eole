# Sources audio

Les sons respiratoires utilisés par Eole proviennent du fichier **Man Breathing**
(BigSoundBank, son `#2195`, auteur Joseph SARDIN) :

- Page source : <https://bigsoundbank.com/man-breathing-s2195.html>
- Fichier original : <https://bigsoundbank.com/UPLOAD/mp3/2195.mp3>
- Licence : CC0 / équivalent domaine public, avec modification, redistribution et
  usage commercial autorisés selon la page source ; l'attribution n'est pas requise.

Les fichiers `eole-inhale.mp3` et `eole-exhale.mp3` sont des extraits locaux du
fichier original. Ils ont été préparés pour l'interface (sélection de passages
d'inspiration et d'expiration nasales, filtrage léger, fondus et normalisation du
niveau sonore). Le traitement ne change pas la licence de la source.
